Stress Level UI

A small HTML and CSS UI experiment that visualizes a daily stress level inside a clean, card-based layout. The focus of this project was on spacing, typography, and building simple vertical progress indicators.

This is a static UI concept built as part of my frontend and UI/UX practice. No frameworks, no tutorials — just experimenting and refining layout structure.

The interface uses Flexbox for centering and alignment, Urbanist for typography, and Font Awesome for icons. Progress bars are styled to grow from the bottom up to represent daily values.

To view the project, simply open index.html in your browser.

Further improvements like animations, responsiveness, and dynamic data may be added later as the project evolves.
